AdGenius AI 🚀

Your AI-Powered Marketing Assistant

AdGenius AI helps small businesses, entrepreneurs, creators, and marketers create marketing content more easily. Generate campaign ideas and promotional content from one convenient dashboard.

✨ Features

- 📝 AI-generated marketing headlines and ad copy
- 📱 Social media captions and hashtags
- 💬 WhatsApp promotional messages
- 🎬 Video scripts and scene-by-scene storyboards
- 🌐 Support for available language, audience, marketing goal, and brand tone options
- 🎨 Marketing design tools and campaign management
- 💾 Save and manage campaigns
- 🔊 Optional voiceover functionality

🛠️ Built With

- Google AI Studio
- Gemma model integration, subject to verification of the configured model and successful API testing
- The frameworks and technologies used in this repository

🚀 Getting Started

1. Clone or download this repository.
2. Install the dependencies according to the project's configuration.
3. Configure the required API credentials using server-side environment variables or your hosting provider's secret settings.
4. Start the application using the instructions for the project's framework.

Security: Never put API keys in frontend code or commit secret credentials to GitHub.

🎯 Project Goal

AdGenius AI aims to make marketing-content creation more accessible to small businesses, independent creators, and entrepreneurs.

🌱 Open Innovation

This project explores how open-weight AI models can help make AI-powered marketing tools more accessible and customizable.
